# C-Hour Introduction

A community invitation from Minjerribah to Australia and Oceania. Explore Community Hours, joyful responsible abundance, personal intelligence, shared capability and locally shaped pilots.

One C-hour recognises one verified hour of voluntary human contribution. It has no monetary equivalent. Communities shape their own recognition and reciprocity.

Live site: https://auraofintelligence.github.io/C-Hour-introduction/

This is a public introduction and reference library for a proposed system. It is not an operational ledger, participant registration service or running personal agent.

## Maintain the website

The site is plain HTML, CSS and JavaScript, with a small Python builder. No third-party JavaScript framework or installation is required.

1. Edit chapter content in `data/chapters.json`, project connections in `data/projects.json`, or shared presentation in `scripts/build.py` and `assets/`.
2. Run `python scripts/build.py`.
3. Run `python scripts/check_site.py`.
4. Preview with `python -m http.server 8765` and open http://localhost:8765.

Original references retain their original bytes. `data/references.json` records source status, hashes and unresolved exact editions. The current planning edition and correction guide explain superseded archive assumptions.

Artwork is generated concept imagery, not photography of operating projects. Image prompts and provenance are recorded in `data/artwork*.json`.
